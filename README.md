> **一件待决的事，进——三份互不可见、必须选边的判断，出。**

三贤人把「一件你不敢自己拍板的事」变成**三份互不相让的判断**：三台人格单元各自独立判断、互不可见，**必须选边**，投赞成必须写出「什么观测会推翻我」，再按规则计票，并把每一票的理由与少数派的异议**逐字留痕**。它是 DeepSeek Harness（DSH）的插件，配套 54 项自动化测试，以及一份对《洞穴奇案》的对照实验报告。

## 它解决什么问题

让大模型帮你做决定，有两种结构性失败，而且都发生在**不可逆**的场合：**和稀泥**——给一份滴水不漏的两面话，读完你仍然站在原地；**许愿机**——顺着提问者的偏好给结论，你听到的是自己想听的。更根本的是**单模型判断无法自证**：同一个问题问两遍可能得到两个答案，而它不会告诉你「我这次不一样了」。

三贤人的答案是「把纪律写进机制，而不是写进提示词的好意」：

| 痛点 | 三贤人的做法 |
|---|---|
| 和稀泥：读完仍站在原地 | **必须选边**——判决只有赞成／反对，**没有弃权**；落在判断域之外也要给判断，把把握写进保留意见 |
| 许愿机：给提问者想听的答案 | **赞成负举证责任**——投赞成必须写出「什么观测会推翻我」；写不出，这一票由系统**记为反对** |
| 单模型判断无法自证 | **三票一致 ＋ 引擎自证**——重大事项任一反对即否决；每条记录带引擎版本与人格哈希 |
| 结论不可复核 | **异议逐字存档**——少数派的理由原样落盘，不进摘要、不可覆盖 |
| 僵局卡死，无人负责 | **降档要签字**——只有最年长的那一台能被再问一次，由她签字改成多数决；权力转移必须留名 |
| 人格是黑盒，改不动 | **人格与契约是外部 Markdown**——每次表决现读，改完下一次即生效，无需重启 |

## 三台是什么

| 单元 | 她是哪一份自我 | 她只问一个问题 |
| --- | --- | --- |
| 少女 · 黄金 | 还没做过 | 这件事**可能**成立吗 |
| 成女 · 乳香 | 正在做 | 这件事**办得成**吗，代价谁付 |
| 熟女 · 没药 | 已经做过太多 | **三十年后**还剩什么 |

三样礼物里只有黄金是给活人的——所以**替「现在还活着的人」说话的那一台，天生是少数派**。

三台各自还带一条**自查**，能把她自己刚写下的赞成翻成反对。例如熟女那条：*「把时间尺度缩到一代人之内，这个判断还成立吗？」*

## 快速开始

要求 DSH `0.2.0-rc.2`（清单里以 `peerDependencies` 声明）。

**A. 本地挂载**——把本目录放进 profile，在 profile 的 `cordis.patch.yml` 里加：

```yaml
- insert:
    - id: tri-sages
      name: ./tri-sages/index.mjs
      config:
        llmMode: live
```

**B. 装成包**：`dsh plugin --profile <名> add <本目录路径>`

装好后两种入口：

- **斜杠命令（给人用）**：`/sages 要不要把旧表删掉` ｜ `/sages critical …` ｜ `/sages history` ｜ `/sages personas` ｜ `/sages help`
- **工具（给模型用）**：`sages_vote(question, context?, criticality?, label?)` ｜ `sages_history(limit?, key?)` ｜ `sages_personas(action?, unit?)`

> ⚠️ **代码改动要重启；人格与契约改完即生效。** 加载器的热重载只重跑 `apply`，不热换 ESM 模块。所以每条账本记录都带 `pluginVersion`、每份报告都打印 `引擎：tri-sages vX.Y.Z`——用来确认**跑起来的到底是哪一版**。

## 可靠性与实测

- **54 项自动化测试全绿**（`npm test`）。其中 46 项不需要 DSH 宿主，CI 跑 `npm run test:offline`；剩下 8 项是 `test/plugin.test.mjs`——本地插件最容易静默失败的一步：它用宿主**真实的工具定义机制**把插件挂载起来，并实际调用三个工具。
- **离线桩**（`llmMode: stub`，不联网、不花钱）可确定性地复现四条规则路径：多数决、一致通过、**僵局拒签**、**僵局降档**，以及**举证责任把一张赞成票打成反对**（3:0 变 2:1）。
- **改动纪律**：改动前先落快照与可回滚备份；试点→全量；报告与原始账本分层留存。
- **实测**：用《洞穴奇案》（富勒 1949 原案五说 ＋ 萨伯 1998 九说）作测量工具，对同一批 6 个议题做了多轮对照，并与 **14 条人类立场**（6 有罪 : 6 无罪 : 2 弃权）逐条比对。结论：判决稳定，且**结构性地偏保守**——原因可定位到三条轴的选择，并据此发现并修复了两个真实缺陷。详见 [refs/](refs/README.md)。

## 局限（诚实说明）

- **三台共用同一套权重。** 「独立」是**人格层面**的独立，不是参数层面的。这是本项目最重要的局限，也是下一步要解决的事（为三份自我各训练一个适配器）。
- **单次读数不是结论。** 逐字相同的输入曾给出不同的票面；把一次结果当判断用之前，先复跑。
- **仪器会漂移。** 同一个 `provider/model` 名可能被换成不同的后端。实测中曾出现输出契约违规率从 2% 升到 33%、延迟从 46–92 秒塌到 17–22 秒，据此把整轮实验判为作废。**跨时间的对照，先验证「模型还是不是原来那个」。**
- **失败按保守默认处理。** 某一台没回话时，它那一票会被记为反对（安全优先）。报告顶部会写明 `⚠ 已表态：N/3 台`，账本保留该台的原始返回。
- **它不是法律或医疗意见。** 洞穴奇案在这里是**测量工具**，不是要它判对。
